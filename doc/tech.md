# テクノロジースタック (tech.md)

## 🛠️ プログラミング言語
- **Rust (Edition 2021)**: 最新安定版（MSRV: 1.75+）。メモリ安全性、ゼロコスト抽象化、高並行性、単一バイナリ配布適性を活かして採用。

## 🏗️ フレームワーク & ライブラリ
- **MCP プロトコル層**:
  - `rmcp` (または stdio JSON-RPC 2.0 / `mcp-core`): Model Context Protocol の公式仕様に準拠した stdio サーバー実装。
- **非同期ランタイム**:
  - `tokio` (features: `["full", "io-std", "macros"]`): 高速・軽量な非同期 I/O 処理基盤。
- **シリアライズ / デシリアライズ**:
  - `serde` (features: `["derive"]`), `serde_json`: タスクデータおよび JSON-RPC メッセージの高速・型安全な変換。
- **CLI パース**:
  - `clap` (features: `["derive"]`): コマンドライン引数（ストレージパスやログレベル設定等）のパース。
- **エラーハンドリング**:
  - `thiserror`: ドメイン固有エラー（GuardrailViolation, TaskNotFound など）の定義。
  - `anyhow`: アプリケーション境界での柔軟なエラー伝播。
- **ロギング / トレーシング**:
  - `tracing`, `tracing-subscriber`: 構造化ロギング。**MCP の stdio 通信（stdout）を破壊しないよう、ログは必ず標準エラー出力（stderr）に限定して出力**する。
- **ファイルアトミック操作**:
  - `tempfile`: タスク状態保存時の安全なアトミック書き込み（Write-Replace）によるデータ破損防止。

## 🧪 テストツール
- **ユニット / 統合テスト**:
  - `cargo test`: 標準テストフレームワーク。
  - `pretty_assertions`: テスト失敗時の差分可視化。
  - `tempfile`: テスト時の隔離された一時ディレクトリ管理。

## 🔧 開発ツール
- **コード品質 & スタイル**:
  - `cargo fmt`: 公式コードフォーマッター。
  - `cargo clippy`: 静的解析・Linter によるベストプラクティス検証。
- **パッケージ管理**:
  - `cargo`: 依存関係およびビルド管理。

## 📦 インフラ / プラットフォーム
- **実行環境**:
  - クロスプラットフォーム対応（Windows, macOS, Linux）。
  - ランタイム不要のスタンドアロン単一バイナリ (`tasks-mcp` / `tasks-mcp.exe`)。
- **MCP クライアント接続形態**:
  - stdio（標準入出力）トランスポートを介したローカルプロセス起動。

## 🔗 外部API / サービス
- **なし (ゼロ外部依存)**:
  - リモート API や外部クラウドサービスとの依存関係を持たず、ローカル環境単体で完全自律稼働する。
